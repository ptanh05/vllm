## 5. Potential Risks

| Risk | Probability | Impact | Mitigation |
|---|---|---|---|
| **FP8 accuracy drop > 0.10** | Low | High | Remove `--quantization=fp8`, keep only `--kv-cache-dtype=fp8_e4m3` |
| **OOM with large batches** | Medium | High | Reduce `--max-num-seqs` and `--max-num-batched-tokens` |
| **TPOT exceeds 45ms ceiling** | Medium | High | Reduce concurrent requests, increase block size |
| **Trace file not available locally** | High | High | Need trace to validate; test with synthetic workload |
| **GPQA question format mismatch** | Low | Medium | Script handles multiple formats (dict, list, label+text) |
| **Docker image not public** | Medium | High | Custom Docker image must be on public Docker Hub |
| **V1 engine not used** | Low | Medium | --attention-backend only works in V1; V0 uses FlashAttn directly |
| **CPU overload (3 cores)** | Low | Medium | 3 CPU cores for 120 concurrent requests may bottleneck scheduling |
| **FlashInfer not available** | Medium | Low | Already have automatic FlashAttention fallback |

## 7. Action Items Before Competition

### Priority 1 (Before Submission)
- [ ] Download `trace-round1.jsonl` from competition portal → root directory
- [ ] Download `gpqa_diamond_100.jsonl` → root directory
- [ ] Run baseline benchmark: `python -m benchmark.benchmark --trace trace-round1.jsonl`
- [ ] Run GPQA: `python benchmark_gpqa.py --questions gpqa_diamond_100.jsonl`
- [ ] Verify accuracy drop Δ ≤ 0.10

### Priority 2 (Optimization)
- [ ] Run autotuner: `python -m benchmark.autotune --trace trace-round1.jsonl --compose-file docker-compose.yml --max-trials 20`
- [ ] Analyze best_config.json from autotune output
- [ ] Profile with: `python -m benchmark.profile --trace trace-round1.jsonl`
- [ ] Run trace analysis: `python -m benchmark.analyze_trace --trace trace-round1.jsonl --output-dir benchmark_output/`

### Priority 3 (Submission)
- [ ] Build custom Docker image (optional): `docker build -f docker/Dockerfile.custom -t your-org/vllm-opt:latest .`
- [ ] Push to Docker Hub: `docker push your-org/vllm-opt:latest`
- [ ] Update docker-compose.yml image tag if using custom image
- [ ] Test server starts: `docker compose up -d && sleep 60 && curl localhost:8000/health`
- [ ] Submit docker-compose.yml to competition portal
